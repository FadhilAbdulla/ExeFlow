Windows programs,
flowing on your Mac

Drop in an .exe or .msi. ExeFlow tells you what it needs, sets up .NET in one click, and opens it. No virtual machine.

Get the source on GitHub Free and open source. Experimental.

From file to open window

  1. Open the file

    ExeFlow reads the file without running it. Nothing starts until you click.

  2. Set up what's missing

    If it needs .NET, you read Microsoft's license, agree, and ExeFlow downloads it from Microsoft and checks it.

  3. Use the program

    After an installer runs, you see the real program with its own icon instead of a folder of helper files.

Kept away from your files

Programs run inside a macOS sandbox that blocks your home folder. It is strong protection but no guarantee, so open only programs you trust.

One environment per file

Each file you open gets its own Windows environment. Remove it and everything it installed goes to the Trash.

Build it yourself

There is no ready-made download yet. You need Xcode, Rosetta and Homebrew. The first build compiles all of Wine, so it takes a while.

brew install mingw-w64 bison freetype gnutls sdl2
git clone https://github.com/FadhilAbdulla/ExeFlow.git
cd ExeFlow
scripts/bundle.sh && open dist/ExeFlow.app

Something doesn't open? Report it on GitHub.
