Open Windows programs on your Mac

Drop in an .exe or .msi. ExeFlow tells you what it needs, sets that up in one click, and opens it. No virtual machine.

Get the source on GitHub Free and open source. Experimental.

How it works

  1. Open the file

    ExeFlow reads the file without running it. Nothing starts until you click.

  2. Set up what's missing

    If it needs .NET, you read Microsoft's license, agree, and ExeFlow downloads it from Microsoft and checks it.

  3. Use the program

    After an installer runs, you see the real program with its own icon instead of a folder of helper files.

Kept away from your files

Programs run inside a macOS sandbox that blocks your home folder. It is strong protection but no guarantee, so open only programs you trust.

One environment per file

Each file you open gets its own Windows environment. Remove it and everything it installed goes to the Trash.

What works today

Results from our test programs on one Apple M4 Pro with macOS 27.2. Your programs may behave differently.

AreaResultNotes
Files, registry, threads, memoryWorks32-bit and 64-bit
Internet and audioWorksHTTPS request and sound output
.NET Framework 4.8WorksSet up by ExeFlow in about 2 to 4 minutes
Direct3D 9WorksBasic drawing only; no full games tested
Direct3D 10 and 11Doesn't workThis rules out most modern games
Kernel drivers and anti-cheatDoesn't workThey need real Windows
Intel MacsUntestedThe app compiles but has never run on one

ExeFlow relies on Apple's Rosetta, which Apple is cutting back in macOS 28.

Build it

There is no ready-made download yet. You need Xcode, Rosetta and Homebrew.

brew install mingw-w64 bison freetype
git clone https://github.com/FadhilAbdulla/ExeFlow.git
cd ExeFlow
scripts/bundle.sh && open dist/ExeFlow.app

Something doesn't open? Report it on GitHub.
